## 9. 任意バックログ

追加機能は、利用者の必要性を確認し、要件と設計を更新した後だけ着手します。

- [x] 活動写真を1枚添付する。
  - 実装：任意のJPEG・PNG・WebP・HEIC・HEIFを1枚、10MB以内で受け付け、長辺2000px以内へ縮小して詳細画面で表示する。HEIC・HEIFはJPEGまたはPNGへ変換し、元ファイルを保存しない。
  - 表示：JPEG・PNG・WebPは投稿前プレビューを表示し、HEIC・HEIFを表示できない場合は投稿後に変換される旨を案内する。
  - 互換性：JPEG拡張子のMPOは先頭画像だけを通常のJPEGへ変換して保存する。
  - 確認：画像の検証、HEIC・HEIF変換、認証付き配信、保存失敗時の後片付けを自動テストで確認済み。

- [x] 本人限定の活動編集を追加する。
  - 実施：活動日、場所、所要時間、袋数、ゴミ種類、コメント、写真を編集できるようにする。
  - 写真：未選択なら維持、新規選択なら差し替え、削除指定なら写真だけを削除する。新規選択と削除の同時指定は拒否する。
  - 認可：本人以外の編集URLへのアクセスは404とし、成功時は`updated_at`をUTCで更新して活動詳細へ303リダイレクトする。
  - 完了条件：正常更新、入力エラー、写真の維持・差し替え・削除、未認証、他人の活動、保存失敗時の後片付けを自動テストで確認する。
  - 確認：所有者制御、内容更新、写真操作、ロールバック、CSRF付き導線を含む自動テストが成功済み。

- [x] 本人限定の活動削除を追加する。
  - 実施：本人の活動詳細から専用確認画面へ進み、CSRF保護されたPOSTで活動を完全削除する。
  - 認可：本人以外または存在しない活動の確認・削除URLは404とし、GETでは削除しない。
  - 関連データ：ゴミ種類と写真情報はDBの`ON DELETE CASCADE`で削除し、DB削除成功後に写真実体を削除する。
  - 画像失敗：写真実体だけ削除できない場合も活動削除は成功扱いとし、安全な内容でログへ記録する。
  - 完了条件：確認画面、キャンセル、正常削除、関連データと写真、CSRF、未認証、他人の活動、DB失敗、画像削除失敗を自動テストで確認する。
  - 確認：所有者制御、完全削除、CASCADE、写真実体の後処理、ロールバック、CSRFを含む自動テストが成功済み。
